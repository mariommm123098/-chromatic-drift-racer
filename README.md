# Chromatic Drift

An artistic dimensional racing game that moves from monochrome 3D linework to colour and finally a folded 2D paper world.

## Controls

- `A` / `←`: steer left
- `D` / `→`: steer right
- `Space`: photon boost
- `Esc`: pause

Touch controls appear automatically on phones and tablets.

The site is deployed automatically to GitHub Pages after every push to `main`.
